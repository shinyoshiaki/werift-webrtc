# Variable: CONNECTION\_WRITE\_CONNECT\_FAILURES

> `const` **CONNECTION\_WRITE\_CONNECT\_FAILURES**: `5` = `5`

A pair is no longer writable once at least this many consecutive checks
went unanswered and [CONNECTION\_WRITE\_CONNECT\_TIMEOUT](CONNECTION_WRITE_CONNECT_TIMEOUT.md) passed since
its last response. libwebrtc: `CONNECTION_WRITE_CONNECT_FAILURES`.
