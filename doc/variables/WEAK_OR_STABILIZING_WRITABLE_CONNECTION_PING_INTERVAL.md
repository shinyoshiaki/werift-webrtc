# Variable: WEAK\_OR\_STABILIZING\_WRITABLE\_CONNECTION\_PING\_INTERVAL

> `const` **WEAK\_OR\_STABILIZING\_WRITABLE\_CONNECTION\_PING\_INTERVAL**: `900` = `900`

Ping interval (ms) of a pair that is weak (a check went unanswered) or
stabilizing (fewer than [MIN\_PINGS\_AT\_WEAK\_PING\_INTERVAL](MIN_PINGS_AT_WEAK_PING_INTERVAL.md) responses
since it began to be monitored). libwebrtc:
`WEAK_OR_STABILIZING_WRITABLE_CONNECTION_PING_INTERVAL`.
